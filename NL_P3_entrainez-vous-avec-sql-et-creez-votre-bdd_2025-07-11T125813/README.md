# Projet 3 — Entraînez-vous avec SQL et créez votre base de données

## Contexte

Le projet consiste à analyser les transactions immobilières réalisées en France en 2020 à partir de données ouvertes, en construisant une base relationnelle puis en répondant à des questions métier avec SQL.

## Modèle de données

Le modèle relationnel s’appuie notamment sur les tables :

- `mutations`
- `locaux`
- `communes`
- `departements`
- `regions`

Les relations permettent de relier les transactions immobilières aux caractéristiques des biens et aux référentiels géographiques.

## Travail réalisé

- Conception d’un modèle relationnel.
- Création d’un dictionnaire de données.
- Préparation et nettoyage des données.
- Création et exploitation d’une base SQLite.
- Écriture de requêtes SQL analytiques.
- Utilisation de jointures, agrégations, filtres temporels et calculs de ratios.

## Outils et technologies

- SQL
- SQLite
- Modélisation relationnelle
- Dictionnaire de données

## Analyses réalisées

Les requêtes permettent notamment d’étudier :

- le nombre d’appartements vendus ;
- les ventes par région ;
- la répartition des ventes selon le nombre de pièces ;
- les départements aux prix au m² les plus élevés ;
- le prix moyen au m² des maisons en Île-de-France ;
- les appartements les plus chers ;
- l’évolution du volume des ventes entre deux trimestres ;
- le classement des régions selon le prix au m² ;
- les communes avec un volume important de transactions ;
- les transactions rapportées à la population.

## Résultats obtenus

- Base relationnelle structurée à partir des données immobilières.
- Douze analyses SQL correspondant à des besoins métier.
- Documentation du modèle et des données.
- Mise en évidence de tendances immobilières à différentes échelles géographiques.

## Compétences démontrées

- Modélisation d’une base de données relationnelle.
- SQL analytique.
- Jointures entre plusieurs tables.
- Agrégations et calcul d’indicateurs.
- Conception d’un dictionnaire de données.
- Passage d’une question métier à une requête SQL.

## Valeur ajoutée

Ce projet démontre la capacité à structurer des données dans un modèle relationnel puis à les interroger pour produire des indicateurs directement exploitables par des utilisateurs métier.
